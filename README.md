# GS-Pedidos.Costos

Sistema de costos, inventario y pedidos en Google Sheets + Google Apps Script,
adaptable a cualquier rubro productivo.

## Qué problema resuelve
Calcular costos reales (con mano de obra, desperdicios y servicios) y llevar
el stock y los pedidos en planillas separadas suele hacerse a mano y con errores.
Este sistema lo automatiza.

## Qué hace
- **Costos retroactivos** con coeficientes de servicios, jornales, materiales y desperdicios.
- **Stock automático** de materiales y productos del inventario.
- **Pedidos con sistema de semáforo**: [explicar qué significa cada color].
- **Descuento automático** de las cantidades pedidas sobre el inventario.
